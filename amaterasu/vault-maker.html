Vault maker

Builds vault.json for the Amaterasu hub. Runs entirely in this browser tab — nothing is uploaded, and there is no network call in this page.

Open this file locally (double-click it). Do not host it on Pages: it would be harmless, but it is a tool, not a page.

AES-GCM, 256-bit key derived with PBKDF2-SHA256 at 310,000 iterations. Only this ciphertext goes into the repo — the page list and passwords never do.
